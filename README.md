# 📊 Maven Market Power BI Dashboard

## 🧾 Project Title / Headline

Maven Market Sales & Performance Dashboard (Power BI)

---

## 📌 Short Description / Purpose

This project presents an interactive Power BI dashboard built to analyze the sales performance of Maven Market, a multinational grocery chain.
It helps track key business metrics such as revenue, profit, transactions, and return rate, enabling data-driven decision-making.

---

## 🛠 Tech Stack

* Microsoft Power BI
* DAX (Data Analysis Expressions)
* Power Query (Data Transformation)
* Data Modeling (Star Schema)

---

## 📂 Data Source

* Maven Market Dataset (CSV files)

  * Customers
  * Products
  * Stores
  * Regions
  * Calendar
  * Transactions (1997–1998)
  * Returns

---

## ✨ Features / Highlights

### 🔹 Business Problem

Maven Market needed a centralized dashboard to monitor sales performance, profitability, and product-level insights across multiple regions.

---

### 🔹 Key Metrics Tracked

* Total Revenue: $1.76M
* Total Profit: $1.05M
* Profit Margin: 59.67%
* Total Transactions: 269K
* Return Rate: 0.99%

---

### 🔹 Dashboard Features

* KPI Cards for quick performance overview
* YTD Revenue analysis by month
* Weekend vs Weekday transaction insights
* Product performance tracking
* Return analysis and profitability metrics

---

### 🔹 Insights

* High profit margin (~60%) indicates strong pricing strategy
* Low return rate (<1%) reflects good product quality
* Majority of transactions occur on weekdays
* Consistent revenue growth throughout the year

---

### 🔹 Tools & Techniques Used

* Data Cleaning & Transformation using Power Query
* Data Modeling with relationships (Star Schema)
* DAX measures for advanced calculations
* Interactive visualizations and filters
